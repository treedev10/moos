NAME
    copy - make a copy of a file

SYNOPSIS
    copy <source> <destination>
    copy <source> <folder>

DESCRIPTION
    copy creates a second file with exactly the same contents as the
    first. After copying, the two files are independent: changing one
    does not change the other.

    If the destination file already exists, copy asks before replacing
    it. The copy gets the current date and time as its modification
    time.

ARGUMENTS
    source        the file to copy (it must exist; a name or a path)
    destination   the name for the copy (1 to 19 letters, digits,
                  dots, dashes or underscores, with a path in front if
                  it goes into another folder). If it is an existing
                  folder, the copy goes there with the source's name.

EXAMPLES
    copy diary.txt diary-backup.txt
        Copied diary.txt to diary-backup.txt (812 bytes).

    cp notes.txt notes2.txt
        The same, using the Unix-style alias.

    copy notes.txt backup
        Copies it into the folder backup, as backup/notes.txt.

MESSAGES
    usage: copy <source> <destination>
        You need to give both names.

    There is no file named 'x'.
        The source file does not exist.

    That file already exists. Replace it? (y/n)
        The destination exists. y overwrites it, n cancels.

    error: source and destination are the same file
        A file cannot be copied onto itself.

    error: no free entries
        All 32 entries (files and folders together) are used. Delete
        something first. Folders cannot be copied.

ALIASES
    cp

TIPS
    Make a copy before big changes - it is an easy way to keep a
    backup.

SEE ALSO
    rename, rm, write
